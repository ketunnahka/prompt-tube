Youtube Recommendation Fixer lets you adjust your YouTube recommendations quickly without going through the hassle of watching a bunch of specific videos or blocking the ones you don't wanna see.

Installation
1. Clone the repository: `git clone https://github.com/yourusername/prompt-tube.git`
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable Developer mode in the top right corner.
4. Click Load unpacked and select the extension directory.
